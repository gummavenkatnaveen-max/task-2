# Operations SLA Analytics

## 1. Project Overview

This project analyzes support and operations tickets to understand
ticket volume, resolution time, SLA performance and breach patterns.

## 2. Business Problem

Operations teams need visibility into ticket workload, resolution
performance and SLA compliance.

## 3. Objectives

- Measure ticket volume
- Analyze resolution time
- Calculate SLA compliance
- Identify SLA breaches
- Analyze root-cause patterns
- Provide actionable insights

## 4. Tools

- Python
- Pandas
- NumPy
- SQL
- Power BI
- Excel

## 5. Dataset

The dataset contains support/operations ticket information including
dates, region, category, priority, channel, customer type, agent,
SLA hours, resolution hours and customer satisfaction.

## 6. Data Cleaning

- Converted date columns
- Checked missing values
- Handled missing regions
- Handled missing channels
- Preserved unresolved dates for pending tickets
- Validated resolution hours
- Removed duplicate records
- Recalculated SLA status

- Ticket volume

- Category analysis

- Monthly trends
- Root-cause patterns
